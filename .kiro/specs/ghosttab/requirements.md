# GhostTab requirements — current revision
Created for Kiroween 2026, Costume Contest. Implementation and first documentation were generated by Kiro; Codex reconciled these requirements after browser QA.
- Accept one HTTP(S) URL per line. Reject other schemes and malformed input. Remove exact duplicate strings.
- Add links with the button or Ctrl/Cmd+Enter. Plain Enter inserts a newline.
- Show the first pending link. Open it through a real anchor in a separate tab with noopener noreferrer; opening does not mark it read.
- Mark read and Skip are separate explicit actions. Both advance to the next pending item.
- Progress counts processed links (read plus skipped); it does not represent measured reading time.
- Persist queue in localStorage and validate restored data. Gracefully handle unavailable storage.
- Export pending URLs as selectable text, with clipboard copy when allowed.
- Provide a demo, a confirmed Clear queue action and a New queue action after completion.
- Support keyboard access, labelled controls, reduced motion and responsive layout.
- Do not fetch URL contents, require accounts, use third-party APIs, or upload queue data.
